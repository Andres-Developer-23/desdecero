--- leccion: hola-mundo
titulo: Tu primer programa
min: 10
resumen: print(), texto entre comillas y el orden en que Python ejecuta las líneas.
@@teoria
Un programa es una lista de instrucciones que el ordenador sigue en orden, de arriba abajo, una línea cada vez. En Python, la instrucción más básica es `print()`: muestra en pantalla lo que pongas entre los paréntesis.

```py
print("Hola, mundo")
print("Estoy aprendiendo Python")
```

Pulsa **ejecutar** en el ejemplo. Verás las dos líneas en el mismo orden en que están escritas.

El texto va entre comillas. Python acepta comillas dobles `"..."` o simples `'...'`, pero tienen que coincidir al abrir y al cerrar. A un texto entre comillas se le llama **string** (cadena de texto).

`print()` también acepta varios valores separados por comas. Los muestra en la misma línea, separados por un espacio. Y un `print()` vacío deja una línea en blanco:

```py
print("Tengo", 3, "gatos")
print()
print("La línea de arriba quedó vacía")
```

Tres detalles que conviene saber desde ya:

- Python distingue mayúsculas y minúsculas: `Print("hola")` da error.
- Cada `print()` termina con un salto de línea.
- Las líneas que empiezan con `#` son **comentarios**: Python las ignora. Sirven para explicar tu código a otras personas y a tu yo del futuro.

```py
# Esto es un comentario: no se ejecuta
print("Esto sí se ejecuta")  # también puedes comentar al final de una línea
```

--- leccion: calculadora
titulo: Python como calculadora
min: 15
resumen: Operadores aritméticos, el orden de las operaciones y la diferencia entre / y //.
@@teoria
Python sabe hacer cuentas. Escribe una operación dentro de `print()` y te muestra el resultado:

```py
print(7 + 3)
print(7 - 3)
print(7 * 3)
print(7 / 2)
```

Estos son los operadores que vas a usar todo el tiempo:

- `+` suma, `-` resta, `*` multiplicación
- `/` división: siempre devuelve un número con decimales (`7 / 2` da `3.5`)
- `//` división entera: descarta los decimales (`7 // 2` da `3`)
- `%` módulo: el resto de la división (`7 % 2` da `1`). Sirve, por ejemplo, para saber si un número es par: si `n % 2` da `0`, es par.
- `**` potencia: `2 ** 10` da `1024`

Las operaciones siguen el mismo orden que en matemáticas: primero potencias, luego multiplicaciones y divisiones, y por último sumas y restas. Usa paréntesis cuando quieras cambiar ese orden o simplemente dejarlo claro:

```py
print(2 + 3 * 4)        # 14: primero la multiplicación
print((2 + 3) * 4)      # 20: primero el paréntesis
print(17 // 5, 17 % 5)  # 3 cajas completas y sobran 2
```

Los decimales se escriben con punto, no con coma: `3.5`, no `3,5`. Con coma, Python entiende que son dos números distintos.

--- leccion: errores
titulo: Leer los errores sin miedo
min: 15
resumen: Qué dice un mensaje de error, cómo encontrar la línea y los tres errores más comunes.
@@teoria
Un error no significa que lo estés haciendo mal: es la forma que tiene Python de decirte exactamente qué no entendió. Programar es, en buena parte, leer errores y corregirlos.

Un mensaje de error tiene dos partes que importan: **el tipo de error** y **la línea** donde ocurrió. Ejecuta este ejemplo:

```py
print("Esta línea funciona")
print(mensaje)
```

Python ejecuta la primera línea y se detiene en la segunda con un `NameError`: está usando un nombre, `mensaje`, que nadie ha definido. La primera línea sí llegó a imprimirse.

Los tres errores que más vas a ver al empezar:

- `SyntaxError`: el código está mal escrito y Python no puede leerlo. Suele ser una comilla o un paréntesis sin cerrar, o que faltan los dos puntos `:` al final de un `if` o un `for`. Con este error no se ejecuta ninguna línea.
- `NameError`: usas un nombre que no existe. Casi siempre es una errata (`pritn` en lugar de `print`) o una variable que todavía no has creado.
- `TypeError`: mezclas tipos de datos que no encajan, como sumar un texto y un número.

```py
print("Tengo " + 30 + " años")
```

Cuando veas un error, sigue siempre los mismos pasos: lee el tipo, ve a la línea indicada (el editor la marca en rojo) y revisa también la línea anterior, porque muchas veces el problema empieza ahí.

--- leccion: variables
titulo: Variables: guardar datos con nombre
min: 15
resumen: Asignar con =, elegir buenos nombres y cambiar el valor de una variable.
@@teoria
Una **variable** es un nombre que apunta a un valor. Se crea con el signo `=`: a la izquierda va el nombre y a la derecha el valor.

```py
nombre = "Lucía"
edad = 28
print(nombre)
print(edad)
```

En programación, `=` no significa "es igual a": significa **asigna**. `edad = 28` se lee "guarda 28 en edad". Por eso puedes cambiar el valor más adelante, incluso a partir del valor anterior:

```py
puntos = 10
puntos = puntos + 5
print(puntos)   # 15
puntos += 5     # forma corta de puntos = puntos + 5
print(puntos)   # 20
```

Reglas para los nombres:

- Pueden tener letras, números y guiones bajos, pero no pueden empezar por un número.
- Sin espacios: usa `precio_total`, no `precio total`. Este estilo con guiones bajos se llama *snake_case* y es el habitual en Python.
- Mayúsculas y minúsculas cuentan: `Edad` y `edad` son variables distintas.
- Elige nombres que expliquen qué guardan: `precio` dice mucho más que `x`.

Las variables se combinan en operaciones igual que los números:

```py
precio = 12.5
cantidad = 4
total = precio * cantidad
print("Total:", total)
```

--- leccion: tipos
titulo: Tipos de datos y conversiones
min: 15
resumen: int, float, str y bool; type() para preguntar el tipo; int(), float() y str() para convertir.
@@teoria
Cada valor en Python tiene un **tipo**, y el tipo decide qué puedes hacer con él. Los cuatro básicos:

- `int`: números enteros, como `42` o `-7`
- `float`: números con decimales, como `3.14` o `2.0`
- `str`: texto, siempre entre comillas, como `"hola"` o `"42"`
- `bool`: verdadero o falso; solo existen dos valores, `True` y `False`

La función `type()` te dice el tipo de cualquier valor:

```py
print(type(42))
print(type(3.14))
print(type("42"))
print(type(True))
```

Ojo con el tercero: `"42"` entre comillas es texto, no un número. Parece lo mismo, pero se comporta distinto:

```py
print(42 + 8)       # 50
print("42" + "8")   # 428: con textos, + los une
```

Para pasar de un tipo a otro se usan funciones con el nombre del tipo:

```py
texto = "25"
numero = int(texto)       # de texto a entero
print(numero + 5)         # 30
print(float("2.5") * 2)   # 5.0
print("Tengo " + str(30) + " años")   # de número a texto
```

`int()` solo funciona con textos que parecen un entero. `int("hola")` o `int("2.5")` producen un `ValueError`.

--- leccion: textos
titulo: Trabajar con texto
min: 20
resumen: f-strings, métodos de texto, len() y posiciones de cada carácter.
@@teoria
Los textos son de lo que más vas a manejar. La forma más cómoda de mezclar texto y variables es la **f-string**: pon una `f` delante de las comillas y escribe las variables entre llaves.

```py
nombre = "Andrés"
edad = 25
print(f"Me llamo {nombre} y tengo {edad} años")
print(f"El año que viene tendré {edad + 1}")
```

Dentro de las llaves cabe cualquier expresión. Para limitar los decimales, añade `:.2f` (dos decimales):

```py
precio = 19.999
print(f"Precio: {precio:.2f}")
```

Los textos tienen **métodos**: funciones que se llaman con un punto detrás del texto. Los más útiles:

```py
frase = "  Aprender Python  "
print(frase.strip())       # quita los espacios del principio y del final
print(frase.upper())       # MAYÚSCULAS
print(frase.lower())       # minúsculas
print(frase.replace("Python", "a programar"))
print(len(frase))          # cuántos caracteres tiene, espacios incluidos
```

Cada carácter tiene una posición que empieza en **0**. Con corchetes sacas un carácter o un trozo:

```py
lenguaje = "Python"
print(lenguaje[0])     # P
print(lenguaje[-1])    # n: los negativos cuentan desde el final
print(lenguaje[0:3])   # Pyt: desde la posición 0 hasta la 3, sin incluirla
```

Los métodos no cambian el texto original: devuelven uno nuevo. Si quieres conservar el cambio, guárdalo: `nombre = nombre.strip()`.

--- leccion: booleanos
titulo: Comparaciones y lógica
min: 15
resumen: ==, !=, <, >, and, or y not: preguntas que se responden con True o False.
@@teoria
Para tomar decisiones, un programa necesita hacerse preguntas de sí o no. En Python esas preguntas son **comparaciones**, y su respuesta es un `bool`: `True` o `False`.

```py
edad = 17
print(edad >= 18)        # False
print(edad == 17)        # True
print(edad != 17)        # False
print("hola" == "Hola")  # False: las mayúsculas cuentan
```

Los operadores de comparación:

- `==` igual a (dos signos; uno solo es asignar)
- `!=` distinto de
- `<` menor, `>` mayor, `<=` menor o igual, `>=` mayor o igual

Para combinar varias preguntas se usan tres palabras:

- `and`: es True solo si **las dos** partes son True
- `or`: es True si **al menos una** parte es True
- `not`: invierte el resultado

```py
edad = 25
tiene_entrada = True
print(edad >= 18 and tiene_entrada)   # True
print(edad < 12 or edad > 65)         # False
print(not tiene_entrada)              # False
```

El resultado de una comparación se puede guardar en una variable, como cualquier otro valor. Así el código se lee casi como una frase: `puede_entrar = edad >= 18 and tiene_entrada`.

--- leccion: if-elif-else
titulo: if, elif y else
min: 20
resumen: Ejecutar código solo cuando se cumple una condición, y la sangría que marca cada bloque.
@@teoria
`if` ejecuta un bloque de código solo si la condición es verdadera. La sintaxis tiene dos detalles que no se pueden olvidar: los **dos puntos** al final de la línea del `if` y la **sangría** (4 espacios) de las líneas que dependen de él.

```py
temperatura = 31
if temperatura > 30:
    print("Hace calor")
    print("Bebe agua")
print("Esta línea se ejecuta siempre")
```

La sangría es la forma que tiene Python de saber qué líneas están dentro del `if`. En el editor, al pulsar Enter después de los dos puntos, la sangría se añade sola.

Con `else` indicas qué hacer cuando la condición es falsa, y con `elif` (abreviatura de *else if*) encadenas más casos. Python comprueba las condiciones de arriba abajo y ejecuta **solo el primer bloque** que se cumple:

```py
nota = 4.2
if nota >= 4.5:
    print("Excelente")
elif nota >= 4.0:
    print("Muy bien")
elif nota >= 3.0:
    print("Aprobado")
else:
    print("Reprobado")
```

Con `nota = 4.2` también se cumple `nota >= 3.0`, pero da igual: Python ya entró en el bloque de "Muy bien" y se salta el resto. Por eso el orden importa: ve de la condición más exigente a la menos exigente.

--- leccion: for-range
titulo: El bucle for y range()
min: 20
resumen: Repetir un bloque un número de veces y recorrer secuencias.
@@teoria
Un **bucle** repite un bloque de código. El bucle `for` recorre los elementos de una secuencia, uno por uno, y en cada vuelta guarda el elemento actual en una variable:

```py
for letra in "Hola":
    print(letra)
```

Para repetir algo un número concreto de veces se usa `range()`, que genera una secuencia de números:

```py
for i in range(5):
    print("Vuelta", i)
```

`range(5)` va de 0 a 4: empieza en 0 y **no incluye** el número final. `range()` admite hasta tres valores:

- `range(fin)`: de 0 hasta fin - 1
- `range(inicio, fin)`: de inicio hasta fin - 1
- `range(inicio, fin, paso)`: avanza de paso en paso, también hacia atrás si el paso es negativo

```py
for n in range(1, 11, 2):
    print(n)          # 1, 3, 5, 7, 9
for n in range(10, 0, -3):
    print(n)          # 10, 7, 4, 1
```

Igual que con `if`, la línea del bucle termina en dos puntos y el bloque lleva sangría. Todo lo sangrado se repite; lo que viene después sin sangría se ejecuta una sola vez, al terminar el bucle.

--- leccion: while
titulo: El bucle while
min: 15
resumen: Repetir mientras se cumpla una condición, y cómo evitar los bucles infinitos.
@@teoria
`while` repite un bloque **mientras** una condición sea verdadera. Se usa cuando no sabes de antemano cuántas vueltas harán falta.

```py
saldo = 100
mes = 0
while saldo > 0:
    saldo = saldo - 30
    mes = mes + 1
print(f"El dinero se acaba en el mes {mes}")
```

En cada vuelta Python vuelve a comprobar la condición. Si nunca deja de cumplirse, el bucle no termina: es un **bucle infinito**. Para evitarlo, asegúrate de que algo dentro del bucle acerque la condición a `False` (aquí, restar del saldo). Si te pasa en este editor, no pasa nada: el programa se detiene solo a los pocos segundos, o puedes pulsar **detener**.

Un uso típico de `while` es repetir una pregunta hasta que la respuesta sea válida:

```py
clave = ""
while clave != "python":
    clave = input("Contraseña: ")
print("Acceso concedido")
```

Dos instrucciones funcionan en cualquier bucle, `for` o `while`:

- `break` sale del bucle inmediatamente.
- `continue` salta al principio de la vuelta siguiente.
@@ejercicio

```txt

¡Despegue!
```
@@inicio

@@solucion

    print(n)
    n -= 1

print("¡Despegue!")
@@pista
La condición es while n > 0:. Dentro, imprime n y réstale 1 (n -= 1). El print del despegue va fuera del bucle, sin sangría.
@@comprobar

--- leccion: acumuladores
titulo: Acumular y contar
min: 20
resumen: El patrón acumulador, los contadores y cuándo cortar un bucle con break.
@@teoria
Muchos problemas se resuelven con la misma receta: crear una variable **antes** del bucle y actualizarla en cada vuelta. Se llama patrón **acumulador**.

```py
total = 0
for n in range(1, 6):
    total += n
    print(f"Sumo {n}: el total va en {total}")
print("Total:", total)
```

Un **contador** es lo mismo, pero suma 1 solo cuando se cumple algo:

```py
frase = "programar en python es divertido"
vocales = 0
for letra in frase:
    if letra in "aeiou":
        vocales += 1
print("Vocales:", vocales)
```

El operador `in` comprueba si algo está dentro de otra cosa: `"a" in "aeiou"` es `True`.

Y `break` corta el bucle en cuanto encuentras lo que buscabas, sin dar vueltas de más:

```py
for n in range(1, 100):
    if n * n > 50:
        print(f"{n} es el primer número cuyo cuadrado pasa de 50")
        break
```

titulo: Tuplas y conjuntos
min: 15
resumen: Datos que no cambian y colecciones sin repetidos.
@@teoria
Además de listas y diccionarios, Python tiene otras dos colecciones que verás a menudo.

Una **tupla** es como una lista que no se puede modificar después de crearla. Se escribe con paréntesis y sirve para datos que van juntos y no deberían cambiar, como unas coordenadas:

```py
punto = (4, 7)
```

Un **conjunto** (`set`) guarda valores **sin repetidos y sin orden**. Es la forma más rápida de eliminar duplicados o de comparar grupos:

```py
visitas = ["ana", "luis", "ana", "sofía", "luis", "ana"]
unicos = set(visitas)
print(f"{len(visitas)} visitas de {len(unicos)} personas distintas")
```

Los conjuntos permiten operaciones de teoría de conjuntos:

```py
python = {"ana", "luis", "marta"}
sql = {"luis", "marta", "pedro"}
print(sorted(python & sql))   # en los dos grupos
print(sorted(python | sql))   # en al menos uno
print(sorted(python - sql))   # solo en python
```

Como un conjunto no tiene orden, para mostrarlo ordenado se usa `sorted()`, que siempre devuelve una lista.

--- leccion: def
titulo: Crear tus propias funciones
min: 20
resumen: def, parámetros y return: escribir una vez, usar muchas veces.
@@teoria
Ya usaste muchas funciones: `print()`, `len()`, `input()`. Una **función** es un bloque de código con nombre que puedes ejecutar cuando quieras. Con `def` creas las tuyas:

```py
def saludar(nombre):
    print(f"¡Hola, {nombre}!")

saludar("Diego")
```

`nombre` es un **parámetro**: una variable que recibe el valor que le pasas al llamar a la función, el **argumento**. Definir la función no ejecuta nada; su código corre cada vez que la llamas.

La mayoría de funciones útiles no imprimen: **devuelven** un resultado con `return`, para que puedas guardarlo o usarlo en otra operación.

```py
def area_circulo(radio):

a = area_circulo(2)
print(a)
print(area_circulo(1) + area_circulo(3))
```

La diferencia entre `print` y `return` es clave: `print` muestra algo en pantalla y nada más; `return` entrega un valor a quien llamó a la función. Cuando Python llega a un `return`, la función termina en ese punto.

Una función puede tener varios parámetros separados por comas, por ejemplo `def imc(peso, altura):`.

--- leccion: parametros
titulo: Parámetros por defecto y alcance
min: 20
resumen: Valores por defecto, argumentos con nombre y por qué las variables de una función son locales.
@@teoria
Un parámetro puede tener un **valor por defecto**, que se usa cuando no le pasas ese argumento:

```py
def saludar(nombre, saludo="Hola"):
    return f"{saludo}, {nombre}"

print(saludar("Laura"))
print(saludar("Laura", "Buenos días"))
print(saludar(saludo="Qué más", nombre="Laura"))
```

En la última llamada se usan **argumentos con nombre**: indicas a qué parámetro va cada valor y el orden deja de importar. Es útil cuando una función tiene muchos parámetros. Los parámetros con valor por defecto van siempre después de los que no lo tienen.

Las variables que creas dentro de una función son **locales**: solo existen mientras la función se ejecuta. Fuera de ella no se pueden usar:

```py
def calcular():
    resultado = 42
    return resultado

valor = calcular()
print(valor)        # 42
print(resultado)    # NameError: resultado solo existía dentro
```

Por eso las funciones se comunican con el exterior a través de sus parámetros (lo que entra) y de su `return` (lo que sale). Si una función necesita un dato, pásaselo como argumento.

```py
mayus = [p.upper() for p in palabras]
print(largas)
print(mayus)
```

--- leccion: try-except
titulo: Manejar errores con try / except
min: 20
resumen: Capturar errores previsibles para que el programa siga funcionando.
@@teoria
Algunos errores no se deben a un fallo tuyo, sino a datos inesperados: el usuario escribe "veinte" cuando pedías un número, o un divisor llega a cero. En vez de dejar que el programa se detenga, puedes **capturar** el error con `try` y `except`:

```py
texto = "veinte"
try:
    numero = int(texto)
    print("Convertido:", numero)
except ValueError:
    print(f"'{texto}' no es un número válido")
print("El programa continúa")
```

Python intenta ejecutar el bloque `try`. Si ocurre un error del tipo indicado, salta al bloque `except` en lugar de detenerse. Si no ocurre nada, el `except` se ignora.

Puedes capturar errores distintos con varios `except`:

```py
def dividir(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        return None

print(dividir(10, 4))
print(dividir(10, 0))
```

Una buena práctica: captura solo el tipo de error que esperas (`ValueError`, `ZeroDivisionError`...). Un `except` sin tipo atraparía cualquier error, incluidos los fallos de tu propio código, y te costaría mucho encontrarlos.

@@solucion
def a_numero(texto):
    try:
        return float(texto.replace(",", "."))
    except ValueError:
        return None

print(a_numero("42"))
print(a_numero("3,5"))
print(a_numero("hola"))

@@teoria
Es hora de juntarlo todo. Vas a programar el clásico juego de adivinar un número: el ordenador piensa un número del 1 al 100 y el jugador intenta adivinarlo. Después de cada intento, el programa le dice si el número secreto es más alto o más bajo.

Para que el ordenador elija un número al azar se usa el módulo `random`. Un **módulo** es un conjunto de funciones listas para usar que se cargan con `import`:

```py
import random

for _ in range(3):
    print(random.randint(1, 100))   # entero al azar entre 1 y 100, ambos incluidos
```

Ejecuta el ejemplo varias veces: cada vez salen números distintos. El guion bajo `_` es el nombre habitual para una variable cuyo valor no vas a usar.

Antes de escribir código, piensa el plan en pasos. Este hábito te servirá en cualquier programa:

1. Elegir el número secreto y poner el contador de intentos a cero.
2. Repetir hasta que el jugador acierte: pedir un número, sumar un intento y decir "más alto" o "más bajo".
3. Al acertar, felicitar e indicar cuántos intentos hicieron falta.

Para el paso 2 viene bien `while True:`, un bucle que no termina por sí solo: sales de él con `break` o, dentro de una función, con `return`.

Para que el comprobador pueda probar tu juego, el número secreto llega como parámetro de la función `jugar(secreto)`. Al comprobar se ignoran las llamadas a `jugar(...)` que escribas fuera de la función, así que puedes dejar activa la última línea para jugar de verdad.

@@solucion
import random

def jugar(secreto):
    intentos = 0
    while True:
        texto = input("Tu número: ")
        try:
            numero = int(texto)
        except ValueError:
            print("Escribe un número entero")
            continue
        intentos += 1
        if numero < secreto:
            print("Más alto")
        elif numero > secreto:
            print("Más bajo")
        else:
            print(f"¡Correcto! Intentos: {intentos}")
            return intentos

# Para jugar de verdad, quita el # de la línea siguiente y pulsa ejecutar:
jugar(random.randint(1, 100))
